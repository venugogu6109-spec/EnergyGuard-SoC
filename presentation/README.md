
# EnergyGuard-SoC Project Presentation

## Project Title
**EnergyGuard-SoC: RTL-to-GDSII Implementation of an Intelligent Energy Monitoring and Protection System**

## Overview
This project demonstrates a Verilog-based digital energy monitoring and protection system and its implementation through RTL design, functional verification, logic synthesis, physical design, timing analysis, and GDSII layout generation.
